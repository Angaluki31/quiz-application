# Python Quiz Application

A command-line quiz application built with Python. It presents multiple-choice questions, checks user answers, calculates scores, and displays the final results.

The application is designed to demonstrate fundamental Python programming concepts through an interactive quiz.

## Features

- Multiple-choice questions with four answer options.
- Automatic answer checking.
- Input validation to prevent invalid responses.
- Randomized question order.
- Automatic score calculation.
- Percentage-based results.
- Performance feedback based on the final score.
- Simple command-line interface.

## Technologies Used

- Python 3
- random - to shuffle questions.
- Lists and dictionaries - to store questions, options, and answers.
- Functions - to organize the program 
- Loops and conditionals - to control quiz execution.

## Requirements

- Python 3 installed on your computer
- A terminal or command-line application.

## Getting Started

1. Clone the repository
2. Navigate into the project folder.
3. Run the application:
	python quiz.py 
		or
	python3 quiz.py 
	
	
## How to Use

1. Run the application.
2. Read each question carefully.
3. Select your answer by entering A, B, C, or D.
4. Receive immediate feedback after each answer.
5. View your final score and percentage after completing the quiz.
